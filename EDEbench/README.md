## Directory Structure

- **`/edefuzz_results`**: The Result of EDEFuzz
- **`/Mockingbird_log`**: The log of our method on APIs, the results are based on these logs and are being organized.
- **`/targetAPI`**: The APIs to be tested, and the ground truth.

## Getting Started

Please refer to the `README.md` file within each directory for specific instructions on how to set up and run the components. Start with `/NodeServer` for the main framework.
