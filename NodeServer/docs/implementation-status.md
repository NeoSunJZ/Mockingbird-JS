## 对最初六类问题的处理

1. **装箱语义**：在首次运行目标代码前适配条件、逻辑表达式、比较、`typeof`、`switch` 与选定的原生转换；DOM 边界拆箱，业务自己创建的普通对象不会由 `raw` 任意拆解。任意 JavaScript 的完全透明性仍未解决。
2. **方法绑定与副本**：移除 structuredClone 前置条件和 `_f_src` 副本绑定。数组写入发生在真实存储；常见方法保持稳定函数身份和动态 `this`。原生内部槽类型做有限处理；自定义类、私有字段和全部跨 realm 类型没有完整模型。
3. **重复求值**：不再生成“执行表达式后再读一遍依赖”的参数。同步 capture 在执行过程中收集来源；复合赋值和自增引用缓存接收者、属性键。短路和条件分支保留原来的惰性求值。
4. **传播与来源**：来源按响应发生次数区分；派生值具有独立值 ID 和父节点。派生对象采用明确标注的保守来源合并，不再伪造 `root[a][newProperty]`。补充简写箭头返回、直接计算参数、解构边界和普通自增自减。没有建立完整的隐式控制依赖模型。
5. **框架边界**：保留 DOM 节点的原生身份，避免迭代给节点套 Proxy 导致 Illegal invocation；原生布尔谓词回调做拆箱；Vue 的原始值追踪盒避免被响应式层再次代理。验证覆盖具体固定版本的生产运行时与渲染场景，不代表所有 React/Vue API、开发构建、编译器和版本。
6. **迭代与日志**：每轮新上下文；用同一配置先跑基线；脚本按 URL 与内容区分；CDP 逐跳处理重定向；单次原子注入；保留完整结构化日志；等待场景稳定和日志 flush；使用候选位置而非 `logIndex === index` 推断进展。错误、覆盖缺口和超时不会被解释为正常完成。

## 必须保留的限制

**React/Vue 的最终状态目前是 `incomplete`。** 渲染一致和已到达 DOM 的字段得到验证，但框架内部派生的 null/undefined 值无法继续附带 Proxy。最新场景报告 `nullish-propagation` 缺口；不能据此宣称所有字段都已分类，或把没有后续事件的字段直接判为未使用。

其他边界：

- `await`/`yield` 所在的传播表达式不放入同步 thunk；报告 suspended-expression。跨 Promise、序列化、worker/iframe realm 的完整来源接力未实现。
- 直接 eval 保留其词法作用域并在执行时报告缺口；Function 动态生成代码同样报告缺口。inline 代码没有全量重写，未知执行栈不能冒充已分析脚本。
- `typeof` 未绑定全局标识符保留原语法，避免破坏未声明变量和 TDZ；任意动态全局访问不是完整支持范围。
- 固定不可写属性按 Proxy 不变量返回原值并报告缺口。structuredClone、私有字段接收者和未适配原生方法仍可能不兼容；行为检查只覆盖配置实际触发的路径。
- DOM/storage 是有限 sink 清单。所有 CSS 属性、导航、网络发送、离屏到显示的全部 DOM 操作、worker 与 WebIDL 类型转换并未全部建模。
- 派生对象、方法摘要和部分宿主对象元数据是保守合并；结果可能过度关联。`precision: conservative` 与祖先关系必须被下游分析器保留，不能按精确字段依赖解释。
- 日志溢出、背压和 flush 超时会使结果不完整。运行时事件不是无成本的，尚未完成代表性站点性能评估。
- 当前基线仅比较活动页面的 URL、标题、正文文本、表单值和页面异常。没有比较所有副作用、布局、时序、多页状态、iframe 内容或服务端状态。
- 仍未实现完整的 EDE 结果分类器、论文实验重现或引擎级追踪。

## 日志迁移

旧的 `_f_src` / `_f_from` 数据属性已移除，避免污染业务对象和序列化。使用 `__mockingbird.meta/labels/raw` 访问当前运行时元数据。

旧 `usevar.log` 由每轮 JSONL 事件代替。事件包含响应来源、值 ID、父值、堆栈及定位信息；脚本 manifest 可以找到每个 generation 的确切代码。`converged`、`incomplete`、`failed` 的语义见项目 README。旧审查报告针对 `cf245f2`，其中行号不能当作修复后代码位置。
