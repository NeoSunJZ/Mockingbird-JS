# 追踪位置选择与输入门控

本轮规则保留装箱、Proxy、AST 和迭代重放。分析范围依据同目录的 JS 表达式/语句研究。

## 1. 选取位置

从堆栈匹配已执行脚本版本，定位最深 AST 节点，再沿当前执行函数内部的父链上行。传播位置与 statement 上下文独立收集，不能在遇到第一个 expression 时丢失 statement。

- `let a = b + c++`：c 的事件对应 update 和 a 的初始化两个候选；b 的事件对应 a 的初始化。重写初始化时也必须保留其中 update 的独立语义。
- `if ((x = data.n + 1) > 3)`：记录 x 的赋值和 test 条件使用。
- `if (ok) { const x = data.n + 1; }`：记录初始化，外层 if 只作为上下文，data.n 不成为条件来源。
- 已改写的表达式不重复处理；其中延后执行的回调体不是已覆盖区域。

## 2. 候选与用途

声明初始化、赋值、update、return/throw、调用/构造/带标签模板和默认导出表达式是候选位置。条件、switch 判别式/实际 case.test、for 的 init/test/update、for-in/of、成员 base/key 等分别记录用途。

独立且结果丢弃的计算不是补代理候选；不删除原计算，也不忽略其中调用和写入。块、函数定义等容器不整体收集来源。没有值操作数的 break/continue/empty/debugger 不补代理。

## 3. 传播约束

传播只能由本次实际输入的代理元数据触发，不以“执行过程中某处读到了来源”作为全部返回值的来源。保留一次求值、短路、接收者和引用语义。

对象属性与数组元素分别保留来源，容器可以代理但不把合并来源下发给所有子属性。未知函数的返回对象、原生操作和异步载体需要明确摘要或缺口，不能自动认为所有成员均有来源。

下面记录本轮实际支持范围与验证，不将研究清单等同于完整实现。

## 4. 已实现的具体规则（2026-09-19）

- `getExpression` 返回 `expressions`、`statements`、`uses`、`candidates`；旧的单个 expression/statement 保留作摘要，不能代替完整列表。
- 同一读取可以选中多个独立效果位置。转换由内向外进行，`result` 标记避免嵌套位置重复改写；新分析不会越过实际函数边界，但仍能进入以后执行的回调体。
- 新插桩不再生成依靠动态读取集合的 `capture`。算术/比较等操作保存本次操作数，调用 `derive(result, inputs, site)`；`capture` 仅保留兼容接口，而且只有显式传入的 inputs 参与传播。
- 声明、赋值、update、返回、抛出、普通调用、构造、默认导出、简写箭头返回、普通解构默认值分别处理。普通模板的转换顺序、短路、getter、动态 this 和一次求值有回归检查。
- 对象/数组字面量按实际属性/元素汇总容器信息；派生容器的未知成员不默认继承该汇总。已有代理字段保留自己的来源；普通函数/方法定义不会因闭包文本中的变量而被代理。
- 用户方法的接收者容器不自动成为返回值来源；读取 this 字段会经 Proxy 和该方法的返回表达式继续传播。原生 String/Array/集合操作等走明确的方法摘要。
- WeakMap/WeakSet 的原生方法接收者得到适配；对象键保留身份，Map/WeakMap 保存的带来源值不会被提前拆箱丢失标签。
- 独立调用的返回值被丢弃时，不继续为返回值传播来源；赋值即使作为独立语句，其写入值仍必须传播。
- switch 判别式和实际 case 值保留控制使用记录；解构默认值单独成为候选。函数参数默认值的临时变量作用域尚未处理，明确报告 `parameter-initializer`。
- 顺带修复命令工具对 XPath 内部引号的破坏，以支持本次 Demo 回放。

## 5. 哪些并未全面支持

研究清单是分析目标，不是已实现能力清单。当前仍有如下边界，不能把无事件当作未使用：

- await/yield 所在的传播表达式、可选链传播、带标签模板、super/private 成员特殊引用、直接 eval、函数参数初始化等会保留原行为并记录缺口；不是给这些表达式套普通同步 thunk。
- for-in/of 目前记录角色并依靠既有代理访问/迭代器保留可用来源，没有建立所有隐式迭代协议、动态键名、资源释放和跨异步的完整模型。
- 未知函数返回对象只做保守摘要，不把它的所有成员都标为来自同一输入；这也意味着某些成员可能缺乏后续来源，需要显示不完整状态。
- null/undefined 仍无法用对象代理携带身份；部分函数返回值或容器操作会产生相应缺口。
- 一般函数只要存在带标记的显式输入，其新原始值结果仍可能按论文门控得到保守关联，例如未知 `f(tainted)` 返回一个常量。这不是精确的因果依赖证明；本轮未实现完整过程间静态分析或隐式控制污点传播。
- 现有 DOM/storage sink 范围保持不变；没有宣称已覆盖 avatar、所有 style/class 写入或完整 EDE 自动分类。
